## 2. Сетевая топология и L2 сегменты

Тестирование осуществляется по сквозной схеме «Генератор (Клиент) ➔ NGFW ➔ Генератор (Сервер)»:

```
+---------------------------------------------------------------------------------+
|                                 Cisco TRex ASTF                                 |
|                               (<TREX_HOST_IP>:8080)                                |
|                                                                                 |
|   [Port 0 / 03:00.0]                                      [Port 1 / 0b:00.0]    |
|    192.168.1.2/24                                          172.10.1.2/24        |
|    Эмуляция Клиентов:                                      Эмуляция Серверов:   |
|    16.0.0.0/8                                              48.0.0.0/8           |
+----------+------------------------------------------------------+---------------+
           |                                                      |
           | VLAN/PortGroup:                                      | VLAN/PortGroup:
           | Ideco_Novum_v23-lan1                       | Ideco_Novum_v23-lan2
           | (Promiscuous: Accept)                                | (Promiscuous: Accept)
           |                                                      |
           +-----------------------+      +-----------------------+
                                   |      |
                    +--------------v------v--------------+
                    |           Тестируемый NGFW         |
                    |                                    |
                    |  - Ideco NGFW Novum v23            |
                    |    eth1: 192.168.1.1/24            |
                    |    eth2: 172.10.1.1/24             |
                    |                                    |
                    |  - PT NGFW Node 1                  |
                    |    eth1-1.0: 192.168.1.5/24        |
                    |    eth1-2.0: 172.10.1.5/24         |
                    +------------------------------------+
```

### Параметры виртуальных коммутаторов (vSwitch PortGroup)
Обе порт-группы сконфигурированы в ESXi в режиме Promiscuous Mode для корректного перехвата сгенерированных TRex пакетов с динамическими MAC/IP:
* **`Ideco_Novum_v23-lan1`:**
  * Promiscuous Mode: `Accept`
  * MAC Address Changes: `Accept`
  * Forged Transmits: `Accept`
* **`Ideco_Novum_v23-lan2`:**
  * Promiscuous Mode: `Accept`
  * MAC Address Changes: `Accept`
  * Forged Transmits: `Accept`

### Статическая маршрутизация на NGFW:
Для корректного прохождения трафика эмулируемых подсетей TRex на обоих NGFW прописаны статические маршруты:
1. `16.0.0.0/8` через интерфейс LAN1 (в сторону `192.168.1.2`).
2. `48.0.0.0/8` через интерфейс LAN2 (в сторону `172.10.1.2`).
3. **No-NAT:** Любое транслирование адресов (SNAT/Masquerade) между `16.0.0.0/8` и `48.0.0.0/8` отключено на обоих шлюзах, чтобы измерять чистую производительность инспекции и фильтрации трафика.
